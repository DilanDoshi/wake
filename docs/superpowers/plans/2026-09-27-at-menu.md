# @-menu Implementation Plan — peers, outside sessions, fuzzy files, subagents

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A conversation's `@` menu offers what Claude Code's does — the fleet's other agents, the machine's other Claude sessions, the project's files by fuzzy search, and the session's subagent types — while `⇥` stays the only accept key.

**Architecture:** A fifth airlock file parses the text replies of local commands (`/model`, `/list-agents`, `/rename`); the daemon asks an idle agent for a bare `/list-agents` (the effort-probe machinery, a second kind) and answers the asking client, keeps claude's peer name in step on Wake's `/name` with a bare `/rename`, and carries `init.agents` on the fleet report; the UI's `mentionMenu` offers peers, outside sessions and `@agent-<type>` in a conversation, and paths come from one capped, fuzzy-ranked `git ls-files` index.

**Tech Stack:** Go 1.26, Bubble Tea/lipgloss, the pty `vt10x` screen harness, VHS + ffmpeg for the demo.

**Spec (agreed in conversation 2026-09-27):** the gap analysis and rulings in the owner's DM (peers in a DM's `@` after one letter — no teams, no `@all`, no parked/ended, not the DM's own agent, the manager's DM included; outside-fleet sessions via headless `/list-agents`; `/name` keeps claude's name via `/rename`; project-wide fuzzy file search replaces the one-directory rule; subagents offered as `@agent-<name>`; `⇥` stays the only accept; a fifth airlock file). Wire facts: `docs/superpowers/notes/2026-09-27-at-menu-findings.md`, fixtures `testdata/stream/list-agents{,-empty}.jsonl`.

## Global Constraints

- No non-test file over **800 lines** (`TestNoNonTestFileCrossesTheHardMax`). At the cap or within ~10 lines: `core/vocabulary.go` 800, `core/protocol.go` 798, `core/wire.go` 797, `ui/slash.go` 794, `core/encode.go` 792, `rpc/wire.go` 792, `ui/fleet.go` 791, `daemon/server.go` 790. New code goes in new files; an edit to a capped file pays for its line.
- The airlock becomes **five files**: `protocol.go`, `wire.go`, `vocabulary.go`, `encode.go`, and the new `localreply.go`. Only these spell Claude's JSON or Claude's reply text; every new literal is classified in `airlock_test.go` (`claudeWireVocabulary` / `deliberatelyGeneric` / `notWireVocabulary`), outbound-only words go in `notInTheCorpus`, and `policedWordCount` moves with a changelog line.
- Every new string on `core.Event` / `core.SessionFacts` is contained (`contain.go`).
- Every new rpc frame kind has a `managerVerbs` (client→daemon) or `notAClientVerb` (daemon→client) verdict in `cmd/wake/mcpguard_test.go`; the new client verbs are **refused** to the manager.
- A new `rpc.SessionStatus` field satisfies the three reflective guards (ui `WithStatus` fold, mcp `agentAuthored`, mcp `notInTheStatusReport` + its count).
- **No fixture may carry an operator's own session names, agents, MCP servers or paths.** `agents` stays a dead key for the scrubber; decode tests use a frame literal copied from the sterile recording (built-ins only). The scrubber and `corpus_test.go` are not weakened.
- Cheap to leave open: no timers, no polls. `/list-agents` is asked when a conversation's `@` menu opens; the file index is built when the menu opens, off the draw goroutine.
- The UI never touches an agent's process; the `git ls-files` subprocess is the UI's own read of the working tree (`bang.go`'s precedent), bounded in time and output.
- The menu **offers, never routes, never takes `↵`**. `⇥` is the only accept (owner's ruling, 2026-09-27).
- Never run `wake` without `WAKE_SOCKET`; never touch `~/.wake` or `~/.claude`. TDD: failing test first. Conventional commits, **no attribution lines**.

## Review Focus

1. **`/list-agents` while every agent is busy, or none is live** — the menu shows fleet names only (and any cached listing), never blocks, never writes a turn into a working agent.
2. **A `/list-agents` reply shape the parser does not recognise** (a new CLI version) — yields no outside sessions, never a wrong row, never the reply leaking into the transcript.
3. **A huge repository** (100k+ files) or a non-git directory — the index is capped and time-bounded; a non-git cwd falls back to the one-directory listing.
4. **Wake's `/name` on an agent mid-turn** — the `/rename` waits for idle (the probe's own gate), and its reply never reaches a client or restored history.
5. **An outside session that shares a fleet agent's name** — offered once, the fleet agent winning; a session's own name never offered to itself.
